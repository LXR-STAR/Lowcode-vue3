# 数据绑定和事件系统使用示例

## 一、数据绑定

### 1. API数据绑定到表格

**场景：从API获取用户数据并显示在表格中**

#### 步骤1：创建API数据源
```
名称：用户列表API
类型：API接口
URL：https://jsonplaceholder.typicode.com/users
方法：GET
数据路径：（留空，直接使用返回数组）
```

#### 步骤2：拖入表格组件并配置列
```
列配置：
- 列1：姓名（字段名：name）
- 列2：邮箱（字段名：email）
- 列3：电话（字段名：phone）
```

#### 步骤3：绑定数据
```
选中表格组件 → 右侧"绑定"面板 → 添加绑定
组件属性：表格数据
数据源：用户列表API
数据路径：（留空）
数据转换：
return data.map(user => ({
  name: user.name,
  email: user.email,
  phone: user.phone
}))
```

#### 效果
预览时表格自动显示API返回的用户数据

### 2. 全局变量控制组件显示

**场景：根据登录状态显示/隐藏管理员面板**

#### 步骤1：创建全局变量
```
名称：登录状态
类型：全局变量
值：false
值类型：布尔值
```

#### 步骤2：绑定到组件可见性
```
选中"管理员面板"组件 → 右侧"绑定"面板 → 添加绑定
组件属性：显示状态
数据源：登录状态
```

#### 步骤3：通过事件修改变量
```
选中"登录"按钮 → 右侧"事件"面板 → 添加事件
事件类型：点击
动作：设置变量
  - 变量名：登录状态
  - 值类型：静态值
  - 值：true
```

#### 效果
点击登录按钮后，管理员面板显示

### 3. API数据绑定到图表

**场景：从API获取销售数据并显示柱状图**

#### 步骤1：创建API数据源
```
名称：销售数据API
类型：API接口
URL：https://api.example.com/sales
方法：GET
数据路径：data.list
```

#### 步骤2：绑定到图表
```
选中图表组件 → 右侧"绑定"面板 → 添加绑定
组件属性：图表配置
数据源：销售数据API
数据转换：
return {
  xAxis: {
    data: data.map(item => item.month)
  },
  yAxis: {},
  series: [{
    type: 'bar',
    data: data.map(item => item.amount)
  }]
}
```

## 二、事件系统

### 1. 点击事件

#### 显示消息提示
```
事件类型：点击
动作：显示消息
  - 消息类型：success/warning/info/error
  - 消息内容：操作成功！
  - 显示时长：3000
```

#### 跳转链接
```
事件类型：点击
动作：跳转链接
  - 跳转地址：https://www.example.com
  - 打开方式：_blank（新窗口）/ _self（当前窗口）
```

#### 显示/隐藏组件
```
事件类型：点击
动作：显示组件
  - 目标组件：选择要显示的组件

事件类型：点击
动作：隐藏组件
  - 目标组件：选择要隐藏的组件

事件类型：点击
动作：切换显示
  - 目标组件：选择要切换显示状态的组件
```

## 三、综合示例

### 登录流程完整示例

#### 1. 创建数据源
```
全局变量：
- 名称：登录状态
- 值：false
- 类型：布尔值

API数据源：
- 名称：登录API
- URL：https://api.example.com/login
- 方法：POST
```

#### 2. 组件布局
```
- 用户名输入框（id: username）
- 密码输入框（id: password）
- 登录按钮（id: loginBtn）
- 管理员面板（id: adminPanel）
- 游客提示（id: guestTip）
```

#### 3. 数据绑定
```
管理员面板 → 绑定 → 登录状态 → 显示状态
游客提示 → 绑定 → 登录状态 → 显示状态（需要取反）
```

#### 4. 事件配置
```
登录按钮 → 点击事件：
  1. 动作：API请求
     - 数据源：登录API
     - 成功后动作：设置变量（登录状态 = true）
     - 失败后动作：显示消息（登录失败）

退出按钮 → 点击事件：
  1. 动作：设置变量
     - 变量名：登录状态
     - 值：false
  2. 动作：显示消息
     - 消息内容：已退出登录
```

## 四、动作类型说明

| 动作类型 | 使用场景 | 配置项 |
|---------|---------|--------|
| 跳转链接 | 页面跳转、外部链接 | URL、打开方式 |
| 显示消息 | 操作反馈、提示信息 | 类型、内容、时长 |
| 设置变量 | 状态管理、数据传递 | 变量名、值类型、值 |
| API请求 | 数据提交、数据获取 | 数据源、参数 |
| 显示组件 | 条件显示、弹窗 | 目标组件 |
| 隐藏组件 | 条件隐藏、关闭弹窗 | 目标组件 |
| 切换显示 | 开关状态、折叠面板 | 目标组件 |

---

## 五、事件类型说明

| 事件类型 | 触发时机 | 适用组件 |
|---------|---------|---------|
| click | 单击时 | 按钮、图片、容器 |
| dblclick | 双击时 | 文本、图片 |
| mouseenter | 鼠标移入 | 所有组件 |
| mouseleave | 鼠标移出 | 所有组件 |
| focus | 获得焦点 | 输入框、文本域 |
| blur | 失去焦点 | 输入框、文本域 |
| change | 值改变 | 表单组件 |
| submit | 表单提交 | 表单容器 |
